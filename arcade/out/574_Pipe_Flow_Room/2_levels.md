NOTES
- Level 1 has only 3 turnable pipe tiles and a straight path from the tank to the drain, making it the easiest level to solve.
- Level 2 adds one turnable pipe tile and a small fixed pipe block that forces a single quarter turn, increasing the path complexity slightly.
- Level 3 adds two more turnable pipe tiles and a second fixed pipe block that forces two turns, making the path longer and harder to solve.
- Level 4 adds two more turnable pipe tiles and a third fixed pipe block that forces three turns, making the path longer and requiring more careful tile rotation.
- Level 5 adds two more turnable pipe tiles and a fourth fixed pipe block that forces four turns, making the path the longest and most challenging level.
