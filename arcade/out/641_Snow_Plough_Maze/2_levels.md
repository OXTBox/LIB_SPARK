NOTES
- Level 1 uses a simple open grid with a long snow return delay so the player can clear routes without worrying about snow erasing progress.
- Level 2 adds a small maze structure that forces the plough to plan a longer route before snow can erase the cleared path.
- Level 3 increases the number of required houses and tighter grid layout, requiring more careful route planning while managing shorter snow return times.
- Level 4 expands the town size and house count, adding more complex paths that demand precise route planning with faster snow return.
- Level 5 presents the hardest layout with the maximum number of houses and the shortest snow return delay, requiring constant route management while clearing all required paths.
